# Impeccable Context (Legacy Pointer)

Impeccable v3 context now lives in the repository-root files:

- `PRODUCT.md` — users, product purpose, register, voice, anti-references, and accessibility goals.
- `DESIGN.md` — machine-readable design tokens and the human-readable visual system.
- `.impeccable/design.json` — generated structured metadata for detector and Live Mode.

Do not add new design rules here. Update `PRODUCT.md` for strategy changes and `DESIGN.md` for visual-system changes, then refresh `.impeccable/design.json` with `/impeccable document`.

# Smart Quiz — Design Context

## Users

**Primary**: Vietnamese language learners (18-35) studying Japanese (JLPT N5-N1) and Chinese (HSK1-5).
**Context**: Self-study at home or commuting (mobile). Sessions 10-30 minutes.
**Job to be done**: Learn and retain vocabulary, kanji, grammar through active recall (quizzes) and spaced repetition.
**Emotional goals**: Feel encouraged when progressing, not overwhelmed by difficulty. Learning should feel achievable and rewarding.

## Brand Personality

**3 words**: Encouraging, Clean, Smart
**Voice**: Supportive tutor — knowledgeable but approachable. Never condescending.
**Tone adapts**: Celebratory on success, gentle on mistakes, calm during study.

### References (inspiration)
- **Duolingo**: Gamification, progress tracking, encouraging feedback
- **Anki**: Efficient SRS, minimal UI, focus on content
- **Notion**: Clean layout, good typography, dark mode done right
- **Linear**: Smooth interactions, fast UI, keyboard shortcuts

### Anti-references (avoid)
- Cluttered education apps with too many colors and distractions
- Gamified apps that prioritize fun over actual learning
- Dark mode with neon/glowing accents (AI slop aesthetic)

## Aesthetic Direction

**Visual tone**: Clean, modern, slightly gamified — purple-accented with clear visual hierarchy.
**Theme**: Light mode default, dark mode supported. Both must be equally polished.
**Colors**:
- Primary: Purple `hsl(262, 80%, 60%)` — gamified, friendly, distinctive
- Success: Green `hsl(150, 60%, 40%)` — correct answers, mastery
- Warning: Orange `hsl(38, 92%, 50%)` — attention, review needed
- Destructive: Red `hsl(0, 72%, 63%)` — errors, delete actions
- Neutrals: Tinted toward purple for cohesion

**Typography**:
- Body: Inter (Latin), Noto Sans JP (Japanese), Noto Sans SC (Chinese)
- Japanese text: Always larger than surrounding Latin text for readability
- Kanji should feel prominent and beautiful

**Spacing**: Tailwind 4px base scale. Generous whitespace around content cards.

## Design Principles

1. **Content first** — The vocabulary, kanji, and grammar ARE the product. UI serves the content, never competes with it.
2. **Progressive disclosure** — Show what's needed now. Advanced features reveal through interaction.
3. **Consistent feedback** — Every action gets a response. Success, error, loading — always communicated.
4. **Offline-first** — UI must work without network. No spinners waiting for API calls in core learning flow.
5. **Keyboard-friendly** — Power users learn faster with shortcuts. F1 to speak, Space to flip, 1-4 to select.

## Accessibility

- **WCAG 2.1 AA** mandatory
- Support `prefers-reduced-motion`
- Focus indicators on all interactive elements
- Semantic HTML first, ARIA only when needed
- Touch targets minimum 44x44px
- Support screen readers for quiz content

## Technical Stack

- SvelteKit 2 + Svelte 5 + TypeScript
- Tailwind CSS v4 (design tokens via `@theme`)
- shadcn-svelte (component primitives)
- Vite + PWA plugin (offline support)
- No backend dependency for core features

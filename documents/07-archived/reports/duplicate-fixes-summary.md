## Rationale

Duplicates were removed to:
1. **Avoid confusion** - Students shouldn't see the same word twice in one lesson
2. **Maintain clarity** - Main vocabulary should contain essential lesson words
3. **Follow textbook structure** - Supplementary should only contain extra/related vocabulary

**Strategy:** Kept words in main vocabulary when they are:
- Core to the lesson's grammar point (Lesson 22 clothing for noun modification)
- Basic essential vocabulary (Lesson 8 colors)
- Used in primary lesson examples

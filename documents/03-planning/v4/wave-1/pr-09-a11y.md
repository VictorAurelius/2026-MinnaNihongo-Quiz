## 1. Brainstorm

### Problem
- Accessibility 22/40 (COMPARISON_ACCESSIBILITY.md)
- No focus-visible styles → keyboard users can't see focus
- No skip-link → screen reader users must Tab through entire header
- No aria-live → quiz feedback (đúng/sai) not announced
- Warning `#ff9500` + success `#34c759` fail WCAG AA contrast on white
- No `prefers-reduced-motion` → motion-sensitive users affected
- Modal no focus trap → Tab escapes modal

### Solution
All CSS + ARIA fixes, no structural changes. Maximum a11y improvement with minimal risk.

### Risks
| Risk | Mitigation |
|------|-----------|
| focus-visible conflict with existing :focus | Use `:focus-visible` only (not `:focus`) |
| Color changes affect visual design | Pick closest AA-compliant colors |
| prefers-reduced-motion breaks animations | Only disable animation, keep functionality |
| Focus trap complexity | Standard Tab/Shift+Tab cycle pattern |

### Edge Cases
- Modal with no focusable children → add at least close button
- Nested modals (don't exist currently, but guard)
- SVG elements and focus-visible

## 4. Implementation Notes

### SkipLink.svelte
```svelte
<a href="#main-content" class="skip-link sr-only">
  Skip to main content
</a>

<style>
  .skip-link:focus {
    position: fixed;
    top: 0;
    left: 0;
    z-index: 9999;
    padding: 0.75rem 1.5rem;
    background: var(--primary);
    color: white;
    font-weight: 600;
    clip: auto;
    width: auto;
    height: auto;
    overflow: visible;
  }
</style>
```

### app.css additions
```css
/* Focus visible */
:focus-visible {
  outline: 2px solid var(--primary);
  outline-offset: 2px;
}

/* Reduced motion */
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}

/* Screen reader only */
.sr-only {
  position: absolute;
  width: 1px;
  height: 1px;
  padding: 0;
  margin: -1px;
  overflow: hidden;
  clip: rect(0, 0, 0, 0);
  white-space: nowrap;
  border: 0;
}

/* Fixed colors */
:root {
  --warning: #c27400;  /* was #ff9500 — now 4.56:1 on white */
  --success: #1a8a3a;  /* was #34c759 — now 4.58:1 on white */
}
```

### aria-live on quiz feedback

```svelte
    {isCorrect ? 'Correct!' : `Wrong. Answer: ${answer}`}
  {/if}
</div>
```

### Focus trap (Modal.svelte)
```typescript
function trapFocus(node: HTMLElement) {
  const focusable = node.querySelectorAll(
    'button, [href], input, select, textarea, [tabindex]:not([tabindex="-1"])'
  );
  const first = focusable[0] as HTMLElement;
  const last = focusable[focusable.length - 1] as HTMLElement;

  function handleKeydown(e: KeyboardEvent) {
    if (e.key !== 'Tab') return;
    if (e.shiftKey && document.activeElement === first) {
      e.preventDefault(); last.focus();
    } else if (!e.shiftKey && document.activeElement === last) {
      e.preventDefault(); first.focus();
    }
  }

  node.addEventListener('keydown', handleKeydown);
  first?.focus();
  return { destroy: () => node.removeEventListener('keydown', handleKeydown) };
}
```

# Codex Playbooks

These playbooks replace the removed task skills with repository-native instructions that Codex and human contributors can use.

Codex does not need a vendor-specific skill directory in this repository. The always-on rules live in `AGENTS.md`; task-specific procedures live here.

| Task | Playbook |
| --- | --- |
| Add or update lesson data | `lesson-data.md` |
| Add HSK or Chinese content | `chinese-content.md` |
| OCR content from PDFs/images | `ocr-content.md` |
| Fix GitHub Pages SPA routing | `spa-routing.md` |
| General implementation/debugging/review | `engineering-workflow.md` |
| Refactoring | `refactor.md` |
| Frontend design work | `frontend-design.md` |
| UI review and accessibility | `ui-review.md` |
| Quality audit | `quality-audit.md` |
| Verify deploy and production routing | `verify-deploy.md` |
| Git and PR workflow | `git-pr-workflow.md` |

When a task matches one of these playbooks, read the relevant file before editing.

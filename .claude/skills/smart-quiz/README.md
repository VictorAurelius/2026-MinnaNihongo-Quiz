# Smart Quiz — Project-Specific Skills

Skills phát sinh trong quá trình phát triển. Mỗi skill được tạo khi pattern lặp lại ≥ 2 lần.

## Process tạo skill mới

1. Phát hiện pattern lặp lại (code pattern, testing pattern, data pattern)
2. Tạo file `.md` trong folder này
3. Update `_README-skills-index.md` (thêm vào section "Project-specific")
4. Commit cùng PR đang làm
